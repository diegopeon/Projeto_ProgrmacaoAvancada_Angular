# Maresia Log — Atividade AngularJS + Desafio Vue.js

Este pacote contém duas versões da mesma proposta visual e funcional:

1. `angularjs-maresia` — atividade principal em AngularJS.
2. `vue-maresia-desafio` — desafio extra em Vue.js com Vite.

## Tema escolhido

A empresa fictícia é a **Maresia Log**, uma operação de logística refrigerada para pequenos produtores de alimentos frescos em Salvador e Região Metropolitana.

O tema foi escolhido para tornar a atividade mais crível e menos genérica: em vez de uma plataforma abstrata de IA, a interface trabalha com um problema realista de negócio — entrega de alimentos frescos com controle de temperatura, rotas, coleta e atendimento a restaurantes.

## Componentes obrigatórios contemplados

- Acordeão
- Paginação
- Barra de progresso
- Abas
- Menu suspenso
- Toast notification

## Observação

Os dados são fictícios, mas foram escritos para parecerem parte de uma operação real, com linguagem de negócio, rotas, bairros, carga refrigerada e status de entrega.
